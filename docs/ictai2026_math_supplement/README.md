# ICTAI 2026 equation supplement

This directory contains the mathematical companion material for Paper 895.
It follows the equation numbering and notation in the final camera-ready
manuscript.

## Files

- `ICTAI2026_equation_derivations_first_principles.pdf` explains Equations
  (1)--(11), their assumptions, and worked numerical examples.
- `verify_math.py` checks the algebraic and numerical claims using only the
  Python standard library.
- `ICTAI2026_math_verification_audit.md` is generated by `verify_math.py` and
  records the result of each check.

## Equation (10) alignment

The camera-ready Equation (10) contains the target-group indicator explicitly:

```text
y_ij = x_ij [1 + (a_j B / mu_tgt,j) 1[g_i = tgt]].
```

The indicator is zero for reference rows, which remain unchanged, and one for
target rows. The PDF explanation and verification script use this same form.
This is a documentation correction: the experiment code already applied the
multiplicative shift only to target rows, so no reported result changes.

## Regenerating the audit

Run from this directory:

```bash
python3 verify_math.py
```

The command should print `PASS` and rewrite
`ICTAI2026_math_verification_audit.md`. Use `--output PATH` to write the audit
elsewhere.
